## Where the sources disagree

Treat these as calls to make with your own evals.
- **Multi-agent**: wins at breadth-first research [A4]; single agent plus skills won in commerce [A23]; one writer with many advisors [S5]; hierarchy at scale [S22].
- **Dynamic tools**: keep the set stable for the cache [A3, S2, O5], or load on demand [A7, S21]. Appending without rewriting the prefix reconciles both.
- **Tool-use examples**: helped 2025 models [A7]; drop them for Claude 5-generation models [A22].
- **Context**: fetch everything up front [S1], or start lean and let the agent fetch [S21].
- **Errors in context**: keep them [S2], or isolate trial-and-error in subagents [S20].
- **Permission prompts**: essential for high-risk actions [S10, S12], or "security theater" [S23]. The middle ground is full autonomy only inside a sandbox with limited credentials [S13].
- **Simulated users in evals**: needed for conversational agents [A11], or a poor proxy next to state snapshots [A23].
- **Build or rent the harness**: build it and own control flow [A1, S1], or use a managed harness that absorbs model churn [A17, O9].
